# 资料契约

下列记录为确定性生成的本地合成资料，不含真实主体信息。不同文件通过标识字段关联，版本、生效时间、缺失状态和回执字段保留原始业务含义。

| 文件 | 字段 | 记录数 |
| --- | --- | ---: |
| `daily_metrics.csv` | `store_id`, `date`, `metric`, `value`, `metric_version`, `source_state` | 120 |
| `store_context.csv` | `store_id`, `region`, `format`, `open_minutes`, `renovation_state`, `peer_group` | 24 |
| `events.csv` | `event_id`, `store_id`, `date`, `event_type`, `campaign_id`, `inventory_state`, `source_ref` | 60 |
| `diagnoses.csv` | `diagnosis_id`, `store_id`, `metric`, `period_start`, `period_end`, `metric_version`, `review_state` | 36 |
| `actions.csv` | `action_id`, `diagnosis_id`, `owner`, `action_type`, `accepted_at`, `due_at`, `execution_state`, `outcome_ref` | 48 |

数据缺失、待审、争议和未回执均表示状态未知或处理中，不能解释成零值或成功。记录中的模拟日期用于复现跨期关系，不表示真实业务发生。
